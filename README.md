# 📊 SkillReel Product Analytics Dashboard

## 🚀 Overview

SkillReel is an AI-powered career growth and skill development platform designed to help learners discover, learn, showcase, and monetize their skills. The Product Analytics Dashboard provides real-time insights into user behavior, engagement, retention, growth, and business performance.

This dashboard enables Product Managers, Business Teams, and Leadership to make data-driven decisions and continuously improve product experience.

# ⭐ North Star Metric

**Monthly Active Skilled Users (MASU)**

Definition:
Users who actively learn, create, engage, or complete skill-building activities within a month.

Formula:

MASU = Total Active Skill Learners per Month
